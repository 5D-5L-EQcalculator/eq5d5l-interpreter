EQ-5D-5L Interpreter

ระบบบันทึกรหัสสุขภาพและคำนวณ Thai EQ-5D-5L Index Value สำหรับการทดสอบทางวิชาการ • ประมวลผลบนอุปกรณ์ของคุณ

1. กรอกข้อมูล

เลือกคำอธิบายที่ตรงกับระดับปัญหาในแต่ละด้านมากที่สุด (1 = ไม่มีปัญหา, 5 = มีปัญหาหรือข้อจำกัดมากที่สุด)

0 = สุขภาพแย่ที่สุดเท่าที่จินตนาการได้ • 100 = สุขภาพดีที่สุดเท่าที่จินตนาการได้
0 — แย่ที่สุด50100 — ดีที่สุด

2. ผลการประเมิน

Health State Profile
Thai EQ-5D-5L Index
EQ VAS

รายละเอียดระดับคำตอบ

คำอธิบายเป็นข้อความที่เรียบเรียงใหม่เพื่อการสาธิด ไม่ใช่ถ้อยคำฉบับทางการที่ได้รับอนุญาต

มิติระดับที่เลือกคำอธิบายเชิงรหัส

Index เป็นค่าอรรถประโยชน์ที่คำนวณจากค่าน้ำหนักประชากรไทย ไม่ใช่เปอร์เซ็นต์สุขภาพ ส่วน EQ VAS เป็นการให้คะแนนสุขภาพตนเองโดยผู้ตอบ ไม่ใช่ Index และไม่ใช่เปอร์เซ็นต์ ระบบไม่ใช้ผลเพื่อวินิจฉัยโรคหรือแบ่งระดับดี/ปานกลาง/แย่

ความละเอียด: ค่าสัมประสิทธิ์ในแหล่งอ้างอิงเปิดเผย 3 ตำแหน่งทศนิยม จึงรายงาน Index จากชุดค่าน้ำหนักที่ปัดเศษแล้ว ไม่ใช่ค่าความละเอียดเต็มจากแบบจำลองต้นฉบับ

3. แหล่งอ้างอิงและสูตร

สูตร: Index = 1 − ผลรวมค่าน้ำหนักของทั้ง 5 มิติ ตามระดับที่เลือก (ระดับ 1 = 0) ไม่มีค่าคงที่เพิ่มเติมในตาราง 4.29
